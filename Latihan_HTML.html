Belajar HTML

HTML (HyperText Markup Language) adalah bahasa markup standar yang dipakai untuk membuat dan menyusun struktur dasar halaman serta isi dari sebuah website agar bisa dibaca dan ditampilkan oleh browser. HTML bukan bahasa pemrograman, melainkan sistem tanda (tag).

Belajar Visual Studio Code Lebih Lanjut

Fungsi HTML

  • Menentukan struktur halaman web
  • Membuat elemen interaktif
  • Menampilkan konten multimedia

Membuat Dokumen HTML

  1. Membuat struktur dasar HTML
  2. Menambahkan konten menggunakan elemen HTML
  3. Menjalankan dan memeriksa hasil di browser
